# 转盘工坊

Vue 3 + Vite 前端，FastAPI + SQLite 后端。本机启动后，Vite 将 `/api` 请求代理到 FastAPI。

## 启动

安装 Node.js 20.19+ 或 22.12+，以及 Python 3.10+（含 pip 和 venv 支持）。在项目目录运行：

```sh
npm install
npm run dev
```

首次启动会创建 `.venv` 并安装后端依赖。打开浏览器访问 <http://127.0.0.1:7645>。前端使用 7645 端口，后端使用 7646 端口。按 Ctrl+C 会停止两个服务，任一服务单独退出时，启动脚本也会停止另一项服务。浏览器标签页可以随时关闭或重新打开。

## 使用

- 内置管理员账号为 `hello_world`。首次创建该账号时，服务使用环境变量 `WHEEL_ADMIN_PASSWORD` 设置初始密码。如果未设置，服务会生成随机密码并在启动终端显示一次。已有管理员账号继续使用原密码。
- 仅 `hello_world` 可在「账号管理」中授予或撤销其他账号的管理员身份，以及停用或恢复管理员账号。管理员可管理普通账号及清空指定账号或全站的转盘数据。身份变更后，已登录的用户可刷新页面更新菜单。
- 普通账号注册后自动开通并直接登录，密码至少 6 位且包含英文字母和数字。升级后的首次启动会开通旧版所有未启用账号，因为旧版使用同一状态记录待开通和停用。管理员可在「账号管理」中停用或恢复账号，停用时保留存档。
- 手动添加时每行一项。导入时先自动提取内容，可在预览中逐行修订，再确认加入转盘。图片与纯扫描 PDF 页通过 [RapidOCR](https://github.com/RapidAI/RapidOCR) 在本机识别中英文，首次识别时加载随依赖安装的模型。Word 段落和 PDF 文本按行提取，表格按非空行提取。
- 支持 PNG、JPEG、WebP、BMP、GIF、TIFF、HEIC、HEIF、DOC、DOCX、XLS、XLSX 和 PDF。单文件最大 20 MB，每个转盘最多 500 项。PDF 最多 100 页，其中使用 OCR 的扫描页最多 15 页。
- 在转盘下方填写抽取数量，单次最多 500 人次。不勾选「允许重复」时，以姓名去重，每人等概率且同批最多抽中一次。勾选后，每次从完整名单中等概率抽取一个选项，同一人可在同批中多次抽中。下一批从完整名单重新开始。随机性来自操作系统。
- 选项和抽取记录按账号保存在 `data/wheel.sqlite3`。退出登录或重启服务后，数据会继续保留。界面显示最近 30 条抽取记录。
- 普通账号可通过「清空我的数据」删除本账号的所有转盘选项和抽取记录。管理员可在「账号管理」清空指定账号或全站的转盘数据。清空须在弹窗中确认。

`npm run build` 可生成前端构建产物。
